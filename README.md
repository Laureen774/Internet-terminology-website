# Internet-terminology-website

A 20-page HTML and CSS website explaining common internet terms. Created for Web application developmebnt assignment.

## Live Site
https://github.com/Laureen774/Internet-terminology-website.git

## Pages Included
1. WWW - World Wide Web
2. TCP/IP - Transmission Control Protocol/Internet Protocol
3. URL - Uniform Resource Locator
4. HTTP - HyperText Transfer Protocol
5. DNS - Domain Name System
6. FTP - File Transfer Protocol
7. Browser
8. HTML - HyperText Markup Language
9. Intranet
10. ISP - Internet Service Provider
11. Malware
12. Search Engine
13. Router
14. Cloud Computing
15. HTTP Cookies
16. Firewall
17. About
18. Home

## Features
- Simple HTML5 structure with semantic tags
- CSS styling for navigation and layout
- Diagrams for each term to aid understanding
- "Next" and "Back" links for easy browsing

## Technologies Used
- HTML5
- CSS3
- Git + GitHub
- GitHub Pages for hosting

## How to Run Locally
1. Clone the repo: `git clone https://github.com/Laureen774/Internet-terminology-website.git
2. Open `index.html` in your browser or use VS Code Live Server
